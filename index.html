Consumo de Energia Elétrica no Brasil

Uma aplicação analítica para investigar evolução temporal, diferenças regionais e setoriais, sazonalidade, demanda, eficiência energética e emissões de CO₂.

Repositório GitHub Abrir Dashboard

Sobre o projeto

O projeto utiliza uma base simulada de consumo de energia elétrica no Brasil para identificar padrões de consumo, períodos de maior demanda, diferenças entre estados e setores e possíveis relações entre temperatura e consumo.
